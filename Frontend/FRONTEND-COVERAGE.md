# Frontend coverage

| BRD area | Frontend implementation |
|---|---|
| Student Profile | registration + profile + admin student management |
| Hostel Accommodation | student applications/cancel + admin approve/reject/assign/unassign + hostel/room CRUD |
| Lab Reservation | lab/date/slot/seat booking + confirm/cancel + admin lab/seat/slot management + booking list |
| Event Registration | event cards/capacity + reserved seat selection + held/confirmed/cancelled registrations + admin event/venue/seat CRUD |
| Complaint Management | student submit/history + admin filtering/status/resolution + category CRUD |
| Certificate Requests | student request/history + admin status/review + type CRUD |
| Fee Payment | fee statement + simulated payment + printable receipt + admin type/assignment/status/delete |
| Notifications | list/filter/mark-read/mark-all + shared navbar unread count |
| Dashboards | role-aware student and administrator summaries |
| Routing | guards, lazy loading, route params, wildcard 404 |
| API access | centralized HttpClient services using environment.apiUrl |
